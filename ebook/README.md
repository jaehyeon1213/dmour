# 『그 사람이 나를 잊을까요?』

디무르 상담 신청자에게 드리는 재회 심리 전자책. A4 69쪽.
중학생도 읽을 수 있는 쉬운 말로 썼습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `그사람이_나를_잊을까요.pdf` | **배포용.** 1.4MB, 폰트 내장. 카톡·메일로 그대로 보내면 됩니다. |
| `그사람이_나를_잊을까요.docx` | **편집용.** 한글(HWP)에서 바로 열립니다. 워드·구글문서에서도 열립니다. |
| `그사람이_나를_잊을까요.html` | 웹 배포용 단일 파일. 폰트까지 안에 들어 있어 인터넷 없이도 똑같이 보입니다. |
| `book.src.html` | **원고.** 내용을 고칠 때는 이 파일만 건드리면 됩니다. |
| `build.py` | 원고 → PDF·HTML 변환 스크립트. |
| `hangul/` | 원고 → 편집용 문서(.docx) 변환 스크립트. |

### 한글(HWP) 파일로 쓰시려면

`.docx` 를 한글에서 열고 **다른 이름으로 저장 → 파일 형식 「한글 문서 (*.hwp)」** 를 고르시면
그 자리에서 .hwp 가 됩니다. 한글 2010 이상이면 다 됩니다.

편집용 문서를 다시 만들려면:

```bash
cd ebook/hangul
python3 parse.py        # 원고에서 내용만 뽑아 content.json 으로
node build_docx.js      # content.json → .docx
```

필요한 것: `pip install beautifulsoup4 lxml`, `npm install docx`.

## 고치고 다시 만들기

```bash
cd ebook
python3 build.py           # HTML + PDF 다시 생성
python3 build.py --check   # 쪽 넘침만 빠르게 확인
```

필요한 것: `pip install fonttools brotli`, 그리고 `~/.fonts/` 에
`NotoSerifKR.ttf` · `NotoSansKR.ttf` · `Cormorant.ttf`
(구글 폰트의 가변 폰트 원본).

## 원고 구조

`book.src.html` 안에서 본문은 두 종류로만 되어 있습니다.

- `<section class="page plate">` — 표지·부속표지·차례처럼 **판을 직접 짠 쪽**
- `<article class="flow">` — 본문. 그냥 문단을 이어서 쓰면 됩니다.
  쪽 나누기는 조판 엔진이 알아서 합니다.

문단을 넣거나 빼도 쪽수는 자동으로 다시 계산되고,
**차례의 쪽수도 실제 결과에 맞춰 자동으로 채워집니다.**
(차례 쪽의 `data-tocref`, 각 장의 `data-tocid` 가 짝을 이룹니다.)

### 자주 쓰는 요소

```html
<div class="research">   연구 노트 (보라색 선)  · .tag / h4 / p / .cite
<div class="case">       상담실에서 (연보라 배경) · p.q 는 내담자 발화
<div class="split">      좌우 두 칸 비교 · .col / .col.warn
<div class="keypoint">   장 끝 요약 (금색 상자)
<div class="note">       주의·보충 (회색 상자)
<div class="pull">       큰 인용문
<ul class="dash">        ─ 목록
<ul class="checklist">   ☐ 체크리스트
<sup class="ref">8</sup>  참고문헌 8번
```

`<em>` 은 기울임이 아니라 **형광펜 강조**로 나옵니다.

## 조판 엔진에 대해

`book.src.html` 맨 아래 스크립트가 원고를 A4 판형에 흘려 넣습니다.
문단은 어절 단위로 쪼개 쪽을 끝까지 채우고, 소제목이 쪽 끝에 혼자 남지 않게 하며,
남는 아래 여백은 블록 사이에 나눠 넣습니다(한 틈에 최대 10mm).

작업하면서 밟았던 함정 세 가지를 기록해 둡니다. 나중에 손볼 때 참고하세요.

1. **폰트 로딩 전에 재면 안 됩니다.** `document.fonts.ready` 는 아직 아무 폰트도
   요청되지 않았으면 즉시 resolve 되어 버립니다. 쓰는 굵기를 `document.fonts.load()`
   로 하나씩 불러온 뒤에 조판해야 글자 폭이 맞습니다.
2. **바닥선은 패딩을 뺀 본문 영역입니다.** 패딩 끝을 기준으로 삼으면
   마지막 줄이 쪽번호 위로 흘러내립니다.
3. **크롬 PDF 출력은 CSS 그라디언트와 SVG 필터를 이미지로 굽습니다.**
   그것도 쪽마다 따로. 종이 질감을 `feTurbulence` 로 넣었더니 PDF가 13MB 늘었고,
   가변 폰트를 그대로 쓰면 쪽마다 서브셋을 새로 심어 11MB가 더 붙었습니다.
   그래서 질감은 작은 PNG 타일로, 폰트는 굵기별 고정 인스턴스로 바꿨습니다.
   → 27MB에서 1.4MB로.

## 내용에 대해

본문의 위 첨자 번호는 부록 B의 실제 논문 번호와 대응합니다(33편).
숫자와 연구 결과를 고치실 때는 부록 B의 번호도 함께 맞춰 주세요.

의도적으로 지킨 선이 몇 가지 있습니다.

- 상대의 마음을 되돌리는 '기술'은 다루지 않습니다.
- 재회 통계는 유리한 쪽만 싣지 않았습니다(8장에서 온오프 관계의 낮은 만족도를 그대로 씁니다).
- 무연락을 밀당이 아니라 회복 기간으로 설명합니다.
- 폭력·강압적 통제는 예외 없이 재회 대상에서 제외하고, 상담 연락처(1366, 109)를 함께 적었습니다.
